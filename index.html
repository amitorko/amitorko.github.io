CIS 641 Term Project

Library Study Room Reservation System

For CIS 641, I am working with a team to develop a web-based study room reservation system for a university library.

The system is designed to make it easier for students to find available study rooms, create reservations, cancel reservations, and check in using a reservation code.

The project uses Python and Streamlit for the application interface and a database for managing users, rooms, and reservation information.

Through this project, I am gaining practical experience with requirements analysis, object-oriented design, software modeling, database integration, GitHub, and collaborative development.
